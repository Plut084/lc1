# 光照

当前使用逐片元 Blinn–Phong 局部光照。底色为纹理颜色乘顶点颜色，顶点颜色只表达材质色，不再预烘焙箱体各面的明暗。

最终颜色为一次环境项，加上每盏灯的漫反射和高光：

```text
L = 从表面指向光源的单位向量
V = 从表面指向相机的单位向量
N = 世界空间单位法线
H = normalize(L + V)
color = albedo * 0.15
      + Σ radiance * (albedo * max(dot(N, L), 0)
                    + 0.25 * pow(max(dot(N, H), 0), 32))
```

背光面不计算直接光及高光；视线处于表面背侧、或半程向量退化时，高光为零。`sample_light` 已计算点光源的距离衰减和聚光灯的锥角衰减，这些权重只应用一次。环境项是固定的近似补光，没有间接光追踪；方向光阴影使用深度贴图判断遮挡。

高光颜色为统一的灰色 `0.25`，光泽指数为 `32`，定义在 `shaders/shader.slang`。指数越大，高光越集中。后续独立材质参数可迁移到材质数据中。当前是传统经验式 Blinn–Phong，不是能量守恒的 PBR 模型。

程序生成的箱体各面拥有独立法线；地面和道路法线朝上。OBJ 保留自带法线，没有法线时使用三角形面法线。顶点法线通过模型矩阵的逆转置变换到世界空间，并在片元阶段重新归一化，因此支持非均匀缩放和镜像变换。零缩放等不可逆模型矩阵会在上传前报错。

## 方向光阴影贴图

当前选择上传列表中第一盏方向有效的方向光投影，默认场景已启用太阳。点光源和聚光灯仍参与照明，但暂不投影；没有有效方向光时直接光不应用阴影。

每个在途帧持有独立的 2048×2048 深度图。深度通道使用单采样、正交投影，覆盖玩家附近 192×192 米的光源空间区域，深度范围为 0.1—512 米。投影中心按光源空间纹素对齐，减轻移动时的抖动。渲染所有已提交的几何体后，通过显式 barrier 从深度附件写入转为片元采样。

主通道只给该方向光的漫反射与高光乘阴影可见度，环境项与其他光源不受影响。使用光栅化深度偏移及小量接收深度偏移减少自阴影条纹，3×3 PCF 进行九次深度比较并求平均；覆盖边缘渐隐，范围外视为受光。当前没有级联阴影、透明材质裁剪或点光源立方体阴影，远处以及相机解锁后移出玩家附近的区域没有阴影。

按 **F3** 在正常场景与全屏深度图预览之间切换。预览展示当前帧的原始深度图：越近越黑，越远越白，未写入区域为白色。这是光源看到的最近表面深度，不是最终地面阴影的黑白遮罩。按 M 切视角、WASD 移动和窗口缩放仍可使用。
